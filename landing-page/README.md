# صفحة اللاندينغ لتطبيق أثر (Athar)

## نظرة عامة
صفحة هبوط احترافية لتطبيق "أثر" لاستعادة الصور والفيديوهات المحذوفة. تم تصميمها لتكون مبيعية واحترافية مع مراعاة تجربة المستخدم العربي.

## الملفات
- `index.html` - الصفحة الرئيسية بتنسيق HTML5
- `style.css` - التنسيقات الاحترافية بالكامل
- `README.md` - هذا الملف

## كيفية الاستخدام

### للعرض المحلي
1. افتح المجلد `landing-page`
2. اضغط مرتين على `index.html`
3. ستفتح الصفحة في المتصفح مباشرة

### للنشر على الإنترنت
1. ارفع المجلد `landing-page` إلى خادم الويب
2. أو استخدم GitHub Pages أو Netlify أو Vercel
3. يمكنك تغيير النطاق (domain) حسب حاجتك

## التخصيص

### تغيير الألوان
في ملف `style.css`، ابحث عن `:root` وغيّر المتغيرات:
```css
--color-primary: #f5a623; /* اللون الأساسي (الذهبي) */
--color-dark: #0a0f16; /* اللون الداكن */
```

### تغيير المحتوى
في ملف `index.html`:
- `title` - عنوان الصفحة
- `.hero h1` - العنوان الرئيسي
- `.hero-subtitle` - النص التوضيحي
- `.feature-card` - بطاقات الميزات
- `.testimonial-card` - آراء المستخدمين

### إضافة صور
لإضافة صور حقيقية:
1. ضع الصور في مجلد `images/`
2. عدّل CSS لاستخدامها كخلفيات:
```css
.hero {
    background: url('images/hero-bg.jpg') center/cover;
}
```
